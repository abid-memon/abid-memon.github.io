Project

Covid dashboards

I created global and country-wise dashboards for publicly available Covid-19 data, so the pandemic could be read clearly at a world level and one country at a time.

Type Data cleaning and dashboards Data Public Covid-19 data, CSV Views Global, by country, by continent

The brief

The brief was to take publicly available Covid-19 data and make it usable: clean it, transform it and sort it, then prepare smaller snippets of the data that the dashboards could be built from.

Raw public data on its own is hard to read. The work was in turning it into clean, focused tables first, and only then into dashboards people could explore by country and by continent.

What I did

Four steps, from raw files to finished dashboards.

  1. 1

    Downloaded and cleaned the data

    I downloaded the public data as .csv files and cleaned it in Microsoft Office, getting the raw files into a shape I could trust before anything was built on top of them.

  2. 2

    Prepared the data snippets in SQL

    Using SSMS and complex MySQL queries, I prepared the smaller snippets of data the dashboards would draw from, one focused cut of the data at a time.

  3. 3

    Checked the work in Excel

    Before anything went into a dashboard, I used Excel pivots and charts to check the work, so errors in the data showed up early rather than in the finished views.

  4. 4

    Built the dashboards in Tableau

    I built the dashboards in Tableau, by country and by continent, with a global view on top, so the same data could be read at whatever level the reader needed.

Tools used

  • Microsoft Office
  • .csv
  • SSMS
  • MySQL
  • Excel
  • Tableau
